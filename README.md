# Heisenberg Tycoon 💎

Fan game **tycoon idle** inspirée de Breaking Bad. 100 % web (HTML/CSS/JS, zéro dépendance), installable en PWA et en APK Android.

## Jouer

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Ou directement sur la GitHub Pages du repo. Sur mobile : installer la PWA (ou l'APK Bubblewrap) — le jeu tourne hors ligne et continue de produire pendant ton absence.

## Boucle de jeu

- **💼 Empire** : 10 affaires (lave-auto → cartel international) à débloquer et niveler, paliers ×2 (niv. 10/25/50/100/200/300/400), managers qui automatisent la production (réserve 2 h, même app fermée)
- **⚗️ Labo** : cuisine, vende, blanchis — argent sale → propre, chaleur DEA à gérer
- **🗺️ Carte** : Albuquerque interactive — lieux, personnages, dialogues, événements
- **📋 Deals** : contrats chronométrés, investissements
- **👥 Équipe** : recrutement, améliorations, boutique de légende (prestige)

Objectif : 10 000 000 $ d'argent propre. *Say my name.*
